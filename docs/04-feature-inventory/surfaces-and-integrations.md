# Surfaces and integrations

[🏠 Home](../../README.md) › [Feature inventory](README.md) › Surfaces and integrations

Every place Claude Code runs and every service it connects to, with what each one requires on Microsoft Foundry and in the headless Linux dev container. **Container** ✅ means the item can be used or launched from inside the container; ⛔ means it runs somewhere else (a host app, a browser, Anthropic's cloud, or GitHub). Built from [Platforms and integrations](https://code.claude.com/docs/en/platforms), [Feature availability](https://code.claude.com/docs/en/feature-availability), and the per-surface pages in the [docs index](https://code.claude.com/docs/llms.txt) for Claude Code **2.1.301** as of 2026-10-15.

> [!NOTE]
> **How to use this page.** For each row, confirm the behavior in the evaluation container, then set **Result** (⏳ → 🟩/🟨/🟥/⏭) and put evidence in `evidence/<ID>/`. Rows with a catalog test in **Covered by** are verified by that test; mark them with the test's result. **Policy** is the *proposed* decision. Changes need an ADR in `logs/decision-log.md`.
